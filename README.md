# MDK.02.01_Var_21
https://github.com/TT-lgtm/MDK.02.01_Var_21/tree/Practice
Тема: Разработать программное обеспечение автоматизированной информационной системы учета компьютеров и комплектующих, имеющихся в учебном заведении. База данных должна содержать сведения о наличии и перемещении компьютеров и их комплектующих внутри учебного заведения: номер компьютера, место нахождения (номер кабинета и материально ответственное лицо), состав компьютера — перечень комплектующих устройств (тип комплектующего устройства, его модель и производитель). Создать экранные формы для ввода и редактирования данных в таблицах и все необходимые выходные отчеты.
В данном дереве представленны диаграммы, блок-схемы и техническое задание на тему, описанную ранее.
Задания практических работ:
- Техническое задание;
- Блок-схема;
- Диаграмма переходов состояний;
- Диаграмма сущность-связь ERD;
- Функциональные диаграммы;
- Варианты использования;
- Диаграммы прецедентов;
- Диаграмма деательности;
- Диаграммы последовательностей состояний;
- Диаграмма классов;
- Тест-кейсы;
- Проверочная работа №1;
- Проверочная работа №2;
